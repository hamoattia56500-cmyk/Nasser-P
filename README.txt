ناصر للتكييف والتبريد — نسخة جاهزة لـ GitHub Pages

محتويات الموقع:
- index.html: الصفحة الرئيسية كاملة.

الرفع:
1) ارفع index.html مباشرة إلى Root داخل Repository.
2) تأكد أن الاسم بالضبط: index.html
3) Settings > Pages
4) Source: Deploy from a branch
5) Branch: main
6) Folder: / (root)
7) Save ثم انتظر حتى يظهر رابط الموقع.

ملاحظة:
النسخة الحالية تجمع التصميم وCSS وSVG والصور المضمّنة داخل ملف HTML، لذلك لا تحتاج مجلد صور منفصل لهذه النسخة.
